# 부서 주간업무 일지 서비스 MVP PRD

## 🎯 핵심 정보

**목적**: 부서 구성원이 주간업무를 손쉽게 기록하고, 관리자는 전 부서 현황을 한곳에서 파악하며 필요 시 PDF로 공유할 수 있게 한다.
**사용자**: 회사/조직 내 부서에 소속되어 주간 업무 보고가 필요한 실무자와, 전체 부서 현황을 취합해야 하는 관리자.

## 🚶 사용자 여정

```
1. 홈 페이지
   ↓ [로그인] / [회원가입] 클릭

2. 로그인 페이지 / 회원가입 페이지
   ↓ 인증 성공

3. 부서 소속 여부 체크 (자동)
   [부서 미선택] → 프로필 페이지 (온보딩 강제, 다른 기능 접근 불가) → 부서 선택 저장
   [부서 선택됨] → 바로 통과
   ↓

4. 주간업무 목록 페이지 (내 부서)
   ↓ [새 일지 작성]        ↓ [일지 항목 클릭]         ↓ [PDF 다운로드]

5. 주간업무 작성 페이지        주간업무 상세/수정/삭제 페이지   PDF 파일 다운로드
   ↓ 저장                    ↓ 저장/삭제/취소             (같은 페이지 유지)
   4번으로 복귀               4번으로 복귀
   (같은 부서 소속이면 작성자와 무관하게 수정·삭제 가능)

   [role = 관리자인 경우, 공통 메뉴에서 진입]
   ↓
6. 관리자 대시보드 페이지 (전체 부서 조회)
   ↓ 부서 선택 → 해당 부서 목록/상세 열람, PDF 다운로드
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 주간업무 작성 | 소속 부서의 새 주간업무 일지를 등록 | 서비스의 핵심 산출물 생성 | 주간업무 작성 페이지 |
| **F002** | 주간업무 목록 조회 | 소속 부서의 주간업무 일지를 주차별로 목록 조회 | 작성된 일지를 확인하는 기본 흐름 | 주간업무 목록 페이지 |
| **F003** | 주간업무 상세 조회 | 개별 주간업무 일지의 상세 내용을 조회 | 목록에서 항목을 열어 전체 내용을 확인하는 기본 흐름 | 주간업무 상세 페이지 |
| **F004** | 부서 선택(온보딩) | 프로필 화면에서 본인이 속한 부서를 선택/저장 | 부서 소속 없이는 어떤 일지 기능도 의미가 없음 | 프로필 페이지 |
| **F005** | 온보딩 강제 리디렉션 | 부서 미선택 사용자는 주간업무 관련 기능 접근 시 프로필 페이지로 강제 이동 | 부서 미소속 상태로 일지 작성/조회가 되면 데이터 무결성이 깨짐 | 프로필 페이지, 주간업무 목록 페이지 |
| **F006** | 부서별 접근 제어 (RBAC) | 부서 소속 사용자는 자신의 부서 일지에 한해 목록조회·상세조회·수정·삭제·신규작성을 작성자와 무관하게 모두 수행 가능. 관리자는 모든 부서의 일지에 대해 동일한 권한(목록조회·상세조회·수정·삭제·신규작성)을 수행 가능 | 부서 간 정보 격리와 부서 내 자유로운 협업 편집이 서비스 신뢰성의 핵심 | 주간업무 목록 페이지, 주간업무 상세 페이지, 관리자 대시보드 페이지 |
| **F007** | 관리자 전체 부서 조회 | 관리자가 부서를 선택해 해당 부서의 주간업무 일지를 열람 | 관리자의 유일한 존재 이유(전체 취합) | 관리자 대시보드 페이지 |
| **F008** | Notion 경유 PDF 다운로드 | 특정 부서의 주간업무 일지를 PDF로 다운로드. 서버가 서비스 소유 Notion 워크스페이스에 해당 부서/주차 데이터로 임시 페이지를 생성하고, 그 페이지를 PDF로 변환해 즉시 전달 | 요청된 핵심 산출물 공유 방식 | 주간업무 목록 페이지, 관리자 대시보드 페이지 |
| **F009** | 주간업무 수정 | 부서 소속 일지를 상세 화면에서 수정(작성자와 무관하게 같은 부서 소속이면 수정 가능) | 부서원 누구나 협업해 최신 상태로 유지해야 함 | 주간업무 상세 페이지 |
| **F010** | 주간업무 삭제 | 부서 소속 일지를 삭제(작성자와 무관하게 같은 부서 소속이면 삭제 가능) | 잘못 작성되었거나 불필요한 일지를 정리하는 기본 CRUD 동작 | 주간업무 목록 페이지, 주간업무 상세 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F011** | 기본 인증 | 회원가입/로그인/로그아웃 (기존 스타터킷 인증 플로우 재사용) | 서비스 이용을 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **F012** | 다크모드 토글 | 라이트/다크 테마 전환 (기존 `next-themes` + `ThemeSwitcher` 재사용) | 반응형/접근성 기본 요구사항 | 전체 공통 레이아웃(모든 페이지 하단 푸터) |

### 3. MVP 이후 기능 (제외)

- 주간업무 항목별 세분화(할 일/이슈/다음 주 계획 등 구조화 필드) — MVP는 자유 텍스트 1개 필드로 시작
- 댓글/피드백, 승인 워크플로우(결재선)
- 부서 관리 화면(부서 생성/수정/삭제 UI) — MVP는 Supabase 대시보드에서 고정 부서 목록을 직접 시딩/관리
- 관리자 역할 부여 UI — MVP는 Supabase 대시보드에서 `role` 컬럼 직접 수정
- 사용자별 Notion 계정 연동(OAuth) — MVP는 서비스 소유 워크스페이스 하나로 처리
- 알림(마감 리마인더 등), 통계/대시보드 차트
- 프로필 상세 관리(아바타 업로드 등 기존 필드 외 확장)

| **사용자 행동** | 주차별 일지 목록 확인, 항목 클릭해 상세로 이동, 신규 작성 진입, PDF 다운로드, 항목 삭제 |
| **주요 기능** | • 부서별 주간업무 일지 목록(최신순, 작성자와 무관하게 같은 부서 전체 일지 노출)<br>• 주차 필터<br>• 부서 접근 제어(본인 부서만 노출, 타 부서 데이터 미노출)<br>• **새 일지 작성** 버튼<br>• 항목별 **삭제** 아이콘(확인 후 즉시 삭제, 작성자 무관)<br>• **PDF 다운로드** 버튼(부서 단위, Notion 경유 변환) |
| **다음 이동** | 항목 클릭 → 주간업무 상세 페이지, 신규 작성 → 주간업무 작성 페이지, 삭제 완료 → 같은 목록 페이지(갱신) |

| **주요 기능** | • 전체 부서 목록에서 부서 선택<br>• 선택한 부서의 주간업무 목록 조회(F002 로직 재사용, 부서 파라미터만 확장)<br>• 항목별 **삭제** 아이콘<br>• **PDF 다운로드** 버튼(부서 단위) |

## 🔗 Notion 경유 PDF 다운로드 — 접근 방식 검토 (F008)

Notion API는 **페이지/데이터베이스 생성·조회·수정은 지원하지만, 서버가 호출 가능한 "PDF로 export" 공식 엔드포인트는 제공하지 않는다.** 이 제약을 감안해 3가지 옵션을 검토한다.

| 옵션 | 방식 | 트레이드오프 |
|------|------|--------------|
| **A. (채택) 서비스 소유 워크스페이스 경유** | "PDF 다운로드" 클릭 시 서버가 서비스 소유 Notion 워크스페이스에 해당 부서/주차 데이터로 임시 페이지를 생성 → 그 페이지를 PDF로 변환해 즉시 다운로드 제공 | Notion 공식 API에 PDF export가 없어, 생성된 페이지를 공유 상태로 전환한 뒤 headless 브라우저(예: Playwright)로 렌더링해 인쇄용 PDF로 변환하는 우회가 필요함. 사용자별 Notion 계정 연동(OAuth) 불필요 — 서비스 소유 워크스페이스 하나로 처리하므로 MVP 구현이 가장 단순함 |
| **B. 기존 Notion DB 연동(읽기 전용)** | 부서가 이미 보유한 Notion 주간업무 DB를 API로 조회해 표시, PDF는 별도 생성 | 이번 프로젝트는 Supabase가 주간업무의 단일 소스(SoT)이므로 "Notion에 이미 데이터가 있다"는 전제가 맞지 않음. 적용하려면 별도 동기화 설계가 추가로 필요 |
| **C. 사용자 개인 Notion 계정 연결(OAuth)** | 사용자가 자신의 Notion 워크스페이스를 OAuth로 연결하고, 본인 워크스페이스로 주간업무를 내보내 PDF 다운로드 | 가장 유연하지만 OAuth 연동/토큰 관리/사용자별 권한 처리 등 MVP 범위를 초과하는 구현 복잡도 |

**MVP 채택안**: 옵션 A. "PDF 다운로드" 버튼 클릭 시 서버가 서비스 소유 Notion 워크스페이스의 부서별 데이터베이스에 해당 주차 데이터를 페이지로 생성하고, 그 페이지를 PDF로 변환해 사용자에게 즉시 전달한다. 사용자별 Notion 계정 연동은 필요 없다.
